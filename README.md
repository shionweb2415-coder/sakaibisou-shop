# さかい美装 オンラインショップ試作品

社内検討用の静的なWebサイトです。実際の注文・決済機能はありません。

## 起動方法
`index.html` をブラウザで開いてください。

## 祭りの写真を入れる
`img/` に画像を保存し、次のファイル名にしてください。
- `matsuri-main.jpg`
- `matsuri-01.png`

商品画像6枚（`product1.png` ～ `product6.png`）も `img/` に入っています。

## 商品を変更する
`products.js` の商品名・説明・価格などを編集します。現在の商品・価格は仮データです。

## 注意
公開前に写真の利用許可、商品情報、価格、注文・決済・個人情報の扱いを確認してください。
