# さかい美装オンラインショップ（試作品）

社長との相談用に作成した、フロントエンドのみのデモです。商品・価格・画像・ショップ文言は仮です。

## ローカルで確認する

1. ZIPを解凍します。
2. `index.html` をブラウザで開きます。
3. 商品の追加、検索、カテゴリ絞り込み、カート操作、デモ注文画面を確認します。

画像とGoogle Fontsの読み込みにはインターネット接続が必要です。読み込めない場合でも、レイアウトと基本操作は確認できます。

## 商品の変更方法

`products.js` の `PRODUCTS` 配列を編集します。

各商品に必要な項目：
- `id`: 商品ごとの一意のID
- `name`: 商品名
- `category`: カテゴリ
- `price`: 税込/税抜を決めたうえでの仮価格（現在は円表示）
- `description`: 商品説明
- `image`: 画像URL、または `assets/` 内の画像パス
- `tag`: 商品画像に表示するラベル。不要なら空文字

## GitHubにアップロードして公開する

1. GitHubで新しい **Public** リポジトリを作成（例：`sakaibisou-shop-demo`）。
2. このフォルダ内のファイルをリポジトリのルートにアップロードしてコミットします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** で `Deploy from a branch` を選び、Branchを `main`、フォルダを `/(root)` にして保存します。
5. 公開URLが表示されたらアクセスして確認します。反映まで数分かかることがあります。

## 注意事項

- このサイトはデモで、注文・決済・メール送信・在庫管理は実装していません。
- 本番公開前に、会社の正式な承認、商品情報・価格・画像の権利確認、特定商取引法に基づく表記、プライバシーポリシー、送料・返品条件、決済・注文管理の仕組みを整えてください。
- 公開リポジトリには、顧客情報、APIキー、パスワードなどの秘密情報を置かないでください。
- 実際の販売開始には、ECプラットフォームまたは安全なサーバーサイドの注文・決済システムが別途必要です。
